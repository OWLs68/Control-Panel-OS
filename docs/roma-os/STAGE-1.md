## 1. Що є

Фундамент зібраний і працює на розмірі iPhone. Застосунок — статичний PWA без
бекенда: ванільний TypeScript, esbuild, один `index.html`, один service worker.

| Блок | Стан |
|---|---|
| A. Основа | Зліпок старої Control Panel у `legacy/control-panel-v1`. Новий фундамент на геометрії NeverMind. TypeScript у тій самій збірці |
| B. Вигляд | Токени Graphite Amber, примітиви (картка, кнопка, чіп, поле, порожній стан, прогрес, бейдж) |
| C. Дані | Конверт сутності (UUID v7, created/updated, мʼяке видалення, поле під порядок змін), доменні сховища з єдиним контрактом, типізовані адаптери, маркування mock/live на екрані |
| D. Crow | Персонаж із позами, зона з бульбашкою і чіпами, згортання свайпом, **один глобальний чат** із трьома станами, UI context envelope, клавіатура, голос українською |
| E. Навігація | Реєстр модулів, барабан із фізикою NeverMind, шторка модулів із порядком |
| F. Екрани | Control (Потребує мене / У роботі / Стан системи / Карта системи), Агенти, Проєкти з блокерами, Памʼять, Події |
| G. Перевірка | 18 юніт-тестів, 26 e2e на viewport iPhone, lint, типи, сторож кордону, збірка — усе зелене |

## 2. Головне архітектурне рішення етапу

**Один чат Crow + UI context envelope.** Не вісім чатів як у NeverMind.

Перед кожним повідомленням застосунок збирає структурований конверт: активний
модуль, екран, сутність, вибраний елемент, проєкт, агент, фільтри, видимий стан,
блокери, виділення. Конверт видно рядком над повідомленнями — його можна
перевірити очима, а не вірити на слово.

Контрольний випадок працює: Проєкти → тап по блокеру → «А чого це заблоковано?»
→ Crow відповідає саме про цей блокер. Перехід між вкладками не починає нову
розмову і не стирає набране.

4. Українські множини ламались після чотирьох («5 блокери») — є `plural()`.
5. Навігація з вибором сутності: перемикання модуля стирало вибір, який щойно

6. Заголовок і підпис у рядку картки зливались в один абзац.

## 5.1. Перемикання живого URL зі старої Control Panel

Стара версія ставила service worker через `registerType: 'prompt'` — такий
worker **не** поступається місцем сам. Без окремого заходу телефон, на якому
колись відкривали стару Control Panel, і далі показував би її з кешу, скільки
б разів не відкривали посилання, а новий worker вічно чекав би у «waiting».

Тому новий worker бере керування одразу при install, а при активації
перевіряє: якщо серед видалених кешів був чужий (не `roma-os-*`) — значить
замінили інший застосунок, і сторінки перезавантажуються один раз, щоб
перемикання завершилось без ручного оновлення.

Самообмежене: з наступної версії видаляються тільки власні старі кеші, тому
звичайне оновлення нікого не перезавантажує.

Перевірено локально, обидва сценарії:
- чужий (Workbox) кеш → worker перебирає керування, чужий кеш видалено,
  сторінку перезавантажено один раз, застосунок малюється;
- звичайне оновлення `roma-os` → кеш замінено, перезавантаження немає.

## 5.2. Поле вводу і вікно чату — перенесено дослівно

Перша версія була написана з нуля і виглядала спрощено. Замінено на
справжній бар NeverMind: розмітка, усі значення CSS, уся механіка жесту.

Що збіглося після переносу (перевірено у браузері): `position:fixed`,
відступи 4px від країв, `bottom = --tabbar-h + 4`, радіус `18 18 10 10`,
фон `rgba(38,42,47,0.72)`, `blur(16px)`, висота A 234px (кеп 320),
висота B 449px, смужка-підказка `28×4` над полем тільки коли чат закритий,
зона ручки ~40px, `translateY(110%)` на закритті.

Кнопки фото/мікрофон/відправка — **32px**, як у донорі, а не 44px.
Це свідомо: бар перенесено, а не перероблено. Вони стоять у боксі 50px
з відступами 8px, тож реальна зона пальця більша за саме коло.
Тест `every tappable target is at least 44px` виносить їх окремим
винятком із поясненням, а не мовчки послаблює поріг.

Фото поки не підключене — кнопка на місці, але vision іде через Hermes,
якого немає. Тап показує це словами.

## 5.3. Таббар — перенесено дослівно

Те саме, що з баром: перша версія була своя. Замінено на справжній барабан
NeverMind — розмітка (`index.html:816-825`), уся CSS (`style.css:330-462`),
фізика (`nav.js:472-663`).

Збіглося після переносу: бар `padding 6px 12px`, `gap 8`, `blur 28`;
капсула `radius 20`, `padding 4`, рамка `1.5px`, чотири внутрішні тіні,
бічні градієнти 36px; трек `gap 2px`, `transition 0.35s`;
`padding-left = half(capsule)`; активна клітинка рівно по центру;
класи `active/near/far` з opacity підписів `1 / 0.7 / 0.45 / 0`.

Кнопка модулів — донорська геометрія `drum-plus-btn` 38×38 з пунктирною
рамкою, всередині іконка-куб Roma OS.

**Зауваження:** у NeverMind бар має насичений колір вкладки, і втоплений
жолоб капсули на ньому добре читається. У Roma OS бар світлий
(`rgba(246,240,230,0.92)`), тож жолоб помітно слабший. Порт дослівний;
якщо на телефоні виглядатиме зам'ято — це один рядок (темніша заливка
капсули), але робити без твого слова не буду.
