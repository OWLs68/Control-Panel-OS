# Roma OS

Інтерфейс-оболонка операційної системи **Roman AI OS**. Не life-tracker,
не щоденник, не admin-панель — ядро продукту це стан і робота самої ОС.
Мобільний сценарій головний: з телефона видно, що відбувається, що потребує
Романа, що роблять агенти, що з проєктами — і можна сказати щось Crow.

> **Починаєш нову сесію?** Читай `CLAUDE.md`, далі `docs/roma-os/HANDOFF.md`
> і `docs/roma-os/STAGE-0.md`. Handoff між сесіями живе тільки тут, у git.

---

## Що це технічно

Статичний PWA без бекенда: ванільний TypeScript, зібраний esbuild у один
IIFE-бандл, один `index.html`, один service worker.

| | |
|---|---|
| Збірка | esbuild (`node build.js` → `dist/`) |
| Мова | TypeScript, strict |
| Стан | localStorage за доменами, конверт сутності з UUID v7 |
| Агент | Crow в інтерфейсі, Hermes як runtime під капотом (поки заглушка) |
| Тести | `node --test` (юніт) + Playwright на viewport iPhone |
| Деплой | GitHub Pages, тільки з `main` |

Фреймворка немає свідомо: застосунок — одна фіксована оболонка з кількома
екранами, і кожен кілобайт на старті видно на телефоні.

## Команди

```bash
npm install
npm run build       # → dist/ (бейдж у шапці каже «vdev»)
DEPLOY_NUMBER=19 npm run build   # бейдж «v19» + дата й час; у CI це номер прогону deploy.yml
npm run serve       # віддає dist/ на http://127.0.0.1:4173
npm run lint
npm run typecheck
npm run test        # юніт-тести
npm run e2e         # Playwright, viewport iPhone
npm run verify      # lint + типи + тести + сторож кордону + збірка
```

```

  modules/            Control, Агенти, Проєкти, Памʼять, Події + реєстр
  nav/                барабан, шторка модулів, оболонка
  crow/               персонаж, зона, чіпи, чат, клавіатура, голос
  hermes/             контракт gateway, заглушка, ЄДИНИЙ кордон назовні

  ui/                 примітиви, шторка, іконки, тост
```

## Правила, які тримають цю збірку

**Документ не скролиться.** `html, body { overflow: hidden }`. Скрол живе
всередині `.screen`. Щойно скролиться сторінка — нижня панель їде разом із
контентом. Це вже ламалось двічі.

**Один шар матового скла на стек.** Дочірні поверхні всередині скляної —
суцільна заливка. Тринадцять вкладених blur колись зламали прокрутку на iOS.

**Один кордон до агента.** Усе, що йде до Crow, проходить через `askCrow`
у `src/hermes/gateway.ts`. `scripts/check-gateway-boundary.mjs` стежить за цим
у CI. Заміна заглушки на реальний Hermes — зміна однієї функції.

**Один чат.** Не вісім, як у NeverMind. Одна історія, одна сесія, глобальний
стан; де саме Роман зараз — передається структурованим UI context envelope
перед кожним повідомленням. Деталі — `docs/roma-os/HANDOFF.md` §0.5.

**Ніяких secrets.** Ні в коді, ні в localStorage, ні в комітах.

## Звідки взяті механіки

`OWLs68/NeverMind` — донор UI/UX, read-only. Барабан, три стани чату, підйом
під клавіатуру, голос українською, шторка, чіпи, конверт сутності перенесені
звідти разом із числами, які там не випадкові. Що саме і з якого файла —
таблиця у `docs/roma-os/HANDOFF.md` §3.

Стара Control Panel (перша спроба, вийшла generic admin-панель) лишилась
у гілці `legacy/control-panel-v1`. З неї взяті тільки ідеї: контракти
адаптерів, конверт `Sourced`, розділення mock/live, рівні ризику L0–L3,
концепція стрічки подій, PWA + деплой.

## Обмеження середовища

- `owls68.github.io` заблокований egress-політикою cloud-сесії — задеплоєний
  сайт звідти не перевірити. Тому smoke-тест проти живого URL винесений у CI.
- WebKit не завантажується у cloud-сесії, тому локально e2e ганяються на
  Chromium з viewport iPhone, а WebKit вмикається у CI (`PW_WEBKIT=1`).
- Pages деплоїться тільки з `main`.
